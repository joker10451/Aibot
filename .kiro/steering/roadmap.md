# Планы развития (Roadmap)

## Этап 4 — Реальная оплата
- [x] Интеграция Telegram Stars (XTR, без банков и карт)
- [x] Инвойс через `send_invoice` с `currency="XTR"`, `provider_token=""`
- [x] Автоматическая выдача доступа после оплаты (`F.successful_payment`)
- [x] Уведомление админу о каждой оплате
- [x] Цена настраивается через `STARS_PRICE` в `.env`

## Этап 5 — База данных
- [x] ~~Заменить in-memory хранилища на SQLite~~ → сделано через Firebase Firestore
- [x] Сохранять: user_id, лимиты, статус оплаты, выбранную модель
- [x] История диалогов не теряется при перезапуске бота
- [ ] Миграции / seed-скрипты для начальных данных

## Этап 6 — Админ-панель
- [x] Команда `/admin` — статистика (пользователи, платные, заблокированные, сообщений)
- [x] Команда `/broadcast <текст>` — рассылка всем пользователям
- [x] Команда `/ban <user_id>` — блокировка пользователя
- [x] Команда `/unban <user_id>` — разблокировка
- [x] Все команды защищены проверкой ADMIN_ID
- [x] Проверка бана при каждом сообщении

## Этап 7 — Тарифы и подписки
- [x] Три тарифа: Free (5 сообщений, 2 модели) / Basic (100/месяц, 4 модели, 100⭐) / Pro (безлимит, 7 моделей, 200⭐)
- [x] Ограничения по моделям для каждого тарифа (FREE_MODELS, BASIC_MODELS, PRO_MODELS)
- [x] Автоматическое обнуление лимитов раз в 30 дней (только basic/pro)
- [x] Поле `tier` и `last_reset` в Firestore
- [x] Проверка доступа к модели при выборе
- [x] Автоопределение тарифа по сумме оплаты (100⭐ = basic, 200⭐ = pro)
