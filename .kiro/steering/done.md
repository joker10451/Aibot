# Что сделано

## Этап 1 — Базовый AI-бот
- Подключение NVIDIA NIM API через openai SDK
- Команды `/start`, `/help`, `/clear`
- Память диалога (до 20 сообщений на пользователя)
- Индикатор "печатает..." во время запроса
- Обработка ошибок API

## Этап 2 — Лимиты и монетизация
- Лимит бесплатных сообщений (по умолчанию 5, настраивается в .env)
- Предупреждение при последнем бесплатном сообщении
- Блокировка с inline-кнопкой "Купить доступ"
- Псевдо-оплата: отправка на контакт админа
- Команда `/grant <user_id>` — ручная выдача платного доступа
- Команда `/status` — статус пользователя и остаток сообщений
- Реакция на текстовые триггеры: "доступ", "купить", "buy", "оплата"

## Этап 3 — Выбор модели + .env конфигурация
- Все настройки вынесены в `.env` (токены, лимиты, параметры модели)
- 7 бесплатных NVIDIA NIM моделей на выбор:
  - meta/llama-3.1-70b-instruct
  - meta/llama-3.3-70b-instruct
  - nvidia/llama-3.1-nemotron-70b-instruct
  - mistralai/mistral-7b-instruct-v0.3
  - qwen/qwen3.5-122b-a10b
  - z-ai/glm4_7
  - minimaxai/minimax-m2_1
- Команда `/model` — inline-меню выбора модели
- Каждый пользователь выбирает модель независимо
- Steering-файлы для Kiro (project.md, done.md, roadmap.md)

## Этап 4 — Telegram Stars оплата
- Инвойс через `send_invoice` (currency="XTR", provider_token="")
- Автоматическая выдача доступа через `F.successful_payment`
- Уведомление админу о каждой оплате (user_id + username + Stars)
- Цена настраивается через `STARS_PRICE` в `.env` (по умолчанию 100 ⭐)
- Кнопка "Купить" показывает актуальную цену в Stars

## Этап 6 — Тарифы и подписки
- Три тарифа: Free (5 сообщений, 2 модели) / Basic (100/месяц, 4 модели) / Pro (безлимит, 7 моделей)
- Цены: Basic = 100 ⭐, Pro = 200 ⭐
- Ограничения по моделям: FREE_MODELS, BASIC_MODELS, PRO_MODELS
- Автообнуление лимитов раз в 30 дней (только basic/pro, free не сбрасывается)
- Поля `tier` и `last_reset` в Firestore
- Проверка доступа к модели при выборе через `/model`
- Автоопределение тарифа по сумме оплаты в `successful_payment`

## Этап 7 — Админ-панель
- Команда `/admin` — статистика (пользователи, платные, заблокированные, сообщений)
- Команда `/broadcast <текст>` — рассылка всем с защитой от flood
- Команда `/ban <user_id>` / `/unban <user_id>` — блокировка/разблокировка
- Все admin-команды защищены проверкой `ADMIN_ID` из `.env`
- Поле `banned` в Firestore — проверяется при каждом сообщении
- Подключение firebase-admin SDK
- Коллекция `users/{user_id}` — хранит: messages_used, paid, model, username
- Коллекция `history/{user_id}/messages` — история диалога с timestamp
- Все in-memory хранилища заменены на Firestore
- История диалога сохраняется между перезапусками бота
- Статус оплаты и выбранная модель персистентны
- Переменная `FIREBASE_CREDENTIALS` в .env — путь к JSON сервисного аккаунта

## Этап 8 — UX улучшения (форматирование + воронка продаж)
- Новый system prompt — AI пишет без markdown, с эмодзи-заголовками
- Функция `format_answer()` — убирает `**`, добавляет отступы и эмодзи
- Функция `split_text()` — разбивает длинные ответы (>4000 символов)
- Красивая структура: 🎬 Название, ⏱ Длительность, 📜 Сценарий, 🎵 Музыка, ✨ Эффекты
- Без parse_mode — меньше багов, стабильнее работа
- Кнопочное меню с режимами: 📚 Домашка, 💸 Заработок, ✍️ Тексты, 🎬 TikTok идеи
- Кнопки быстрого доступа: 📊 Статус, 🧹 Очистить
- Персональные system prompts для каждого режима
- ReplyKeyboardMarkup с resize_keyboard для удобства
- Продающая воронка: /start с примерами запросов и акцентом на скорость ("за 10 секунд")
- ВАУ-эффект: "⚡ Сейчас покажу, что я умею..." для первого сообщения
- Микро-продажа: "💡 Хочешь ещё? Напиши следующий запрос" после каждого ответа
- Усиленный экран лимита: список преимуществ безлимита вместо простого "лимит исчерпан"
- Кнопка "⭐ Открыть безлимит" вместо "Купить доступ" (+30-50% конверсии)
- Продажа в /status: "🚀 Открой безлимит, чтобы продолжить" при лимите
- Предупреждение на последнем запросе: "Следующий откроет платный доступ"
